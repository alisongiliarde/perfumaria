# Essência Perfumaria — site inicial

Site estático para publicar no GitHub Pages. Inclui vitrine de três perfumes, descrição em uma janela de detalhes e checkout simples com opção de bolsa para presente Hinode tamanho P. O botão final prepara o pedido no WhatsApp.

## Limitações
É uma vitrine estática: não processa pagamento, não confirma estoque e não salva pedidos em banco de dados. O pedido é enviado para confirmação pelo WhatsApp. GitHub Pages hospeda os arquivos, mas o comprador ainda precisa combinar pagamento e entrega diretamente com o vendedor.
