# Essência Perfumaria — site inicial

Site estático para publicar no GitHub Pages. Inclui vitrine de três perfumes, descrição em uma janela de detalhes e checkout simples com opção de bolsa para presente Hinode tamanho P (+R$ 7,00). O botão final prepara o pedido no WhatsApp.

## Antes de publicar
1. Abra `script.js`.
2. Troque `55DDDNÚMEROAQUI` pelo número de WhatsApp com código do país e DDD, somente números. Exemplo fictício: `5511999999999`.
3. Confira preços, descrições e disponibilidade.
4. As descrições atuais são textos de apresentação provisórios baseados no visual dos frascos; não afirmam notas olfativas ou duração que não foram confirmadas pelo fabricante.
5. A bolsa de presente foi cadastrada como opção adicional de R$ 7,00, conforme informado.

## Publicar no GitHub Pages
1. Crie um repositório público chamado `perfumaria`.
2. Envie `index.html`, `style.css`, `script.js` e a pasta `assets`.
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**, branch `main` e pasta `/ (root)`, depois salve.
5. Aguarde a publicação. O endereço será parecido com `https://alisongiliarde.github.io/perfumaria/`.

## Limitações
É uma vitrine estática: não processa pagamento, não confirma estoque e não salva pedidos em banco de dados. O pedido é enviado para confirmação pelo WhatsApp. GitHub Pages hospeda os arquivos, mas o comprador ainda precisa combinar pagamento e entrega diretamente com você.
